Principal Component Analysis (PCA)

Principal Component Analysis (PCA) is a dimensionality reduction technique used to transform high-dimensional data into a lower-dimensional representation while retaining the most important variance in the dataset. By doing so, PCA helps in visualizing complex data, reducing computational cost, and eliminating noise. The main idea behind PCA is to identify new axes (principal components) that maximize the variance in the dataset, effectively summarizing the original features with fewer dimensions.

Clustering Analysis

Clustering is an unsupervised machine learning technique used to group data points based on their similarities. In this project, clustering helps identify patterns in asteroid trajectories, allowing for early detection of potential collision risks.

View the code For Clustering: Github

Types of Clustering Methods

We explored three clustering methods: K-Means, Hierarchical Clustering, and DBSCAN. Each method provides unique insights into asteroid movement patterns.

K-Means Clustering

  • Partition-based method: Divides asteroids into k clusters based on trajectory features like velocity and distance.
  • Distance metric: Uses Euclidean distance to assign points to clusters.
  • Strengths: Efficient for large datasets, useful for identifying asteroid groups with similar motion.
  • Weaknesses: Assumes clusters are spherical, struggles with irregular asteroid paths.

Hierarchical Clustering

  • Tree-based method: Builds a hierarchical representation of asteroid clusters.
  • Distance metric: Uses various metrics (Euclidean, Manhattan) to form clusters.
  • Strengths: No need to predefine the number of clusters, useful for detecting nested asteroid groups.
  • Weaknesses: Computationally expensive for large asteroid datasets.

DBSCAN (Density-Based Clustering)

  • Density-based method: Identifies asteroid clusters based on density.
  • Distance metric: Uses epsilon (ε) radius and minimum points (minPts) for clustering.
  • Strengths: Detects asteroid clusters of arbitrary shapes and is robust to noise (e.g., outliers or erratic asteroids).
  • Weaknesses: Requires careful tuning of ε and minPts to balance detection accuracy.

In our Asteroid Collision Prediction project, clustering is crucial for:

Association Rule Mining (ARM)

Association Rule Mining (ARM) is a data mining technique aimed at uncovering interesting relationships, patterns, and associations within large datasets. It is widely used in various domains, such as market basket analysis, to identify sets of items that frequently co-occur in transactions.​ ARM relies on three key metrics to evaluate the strength of association rules:

  • Support: The proportion of transactions in which a given rule holds true.
  • Confidence: The probability that the rule's consequent is true given that the antecedent is true.
  • Lift: The strength of an association rule relative to its expected probability.

View the code For ARM: Github

Association Rules

An association rule is an implication of the form {A} → {B}, where A and B are disjoint itemsets. The rule suggests that the presence of itemset A in a transaction implies the presence of itemset B. The strength and significance of such rules are evaluated using the measures of support, confidence, and lift.

The Apriori Algorithm

The Apriori algorithm is a foundational method in ARM, designed to identify frequent itemsets in large datasets and subsequently generate association rules. It operates on the principle that all non-empty subsets of a frequent itemset must also be frequent. This property allows the algorithm to efficiently prune the search space by eliminating itemsets that do not meet the minimum support threshold.​

How the Apriori Algorithm works:

  • Identify Frequent Individual Items: The algorithm begins by scanning the dataset to determine the support of individual items and identifies those that meet or exceed the minimum support threshold.​
  • Generate Candidate Itemsets:Using the frequent individual items, the algorithm generates candidate itemsets of length two and calculates their support.​
  • Repeat Iteratively:Steps 2 and 3 are repeated, increasing the length of the itemsets by one in each iteration, until no more frequent itemsets are found.​
  • Generate Association Rules:From the frequent itemsets identified, the algorithm generates association rules and computes their confidence and lift to assess their significance.​

    Naïve Bayes Classification

    Naïve Bayes (NB) is a family of simple yet powerful probabilistic classifiers based on Bayes’ Theorem with a strong (naïve) assumption that all features are conditionally independent given the class label. Despite this simplifying assumption, Naïve Bayes often performs surprisingly well on a wide range of real-world datasets, especially in high-dimensional problems.

    Bayes’ Theorem

    Naïve Bayes uses Bayes’ Theorem to calculate the probability of a class given a set of features:

    P(Class | Features) = (P(Features | Class) × P(Class)) / P(Features)

    Figure 1: Visual interpretation of Bayes' Theorem showing prior, likelihood, and posterior.

    What does Naïve Bayes do?

    Naïve Bayes computes the probability of each class given a set of input features and selects the class with the highest posterior probability. It models the probability of the data for each class and uses Bayes’ Theorem to invert the relationship to compute the most likely class for unseen data.

    When and Why is it Used?

    • Text classification: Spam detection, sentiment analysis, and document categorization.
    • Medical diagnosis: Predicting diseases based on symptoms.
    • Real-time predictions: Because it is fast and computationally efficient.
    • Imbalanced datasets: Performs well even when classes are not evenly distributed.

    NB is particularly useful when the dataset is high-dimensional, the features are categorical or discrete, and model interpretability and speed are important.

    Multinomial Naïve Bayes

    Multinomial Naïve Bayes (Multinomial NB) is one of the most commonly used algorithms in natural language processing, particularly effective for tasks such as spam detection, sentiment analysis, and topic classification. It is designed for scenarios where features represent discrete counts, such as the number of times a word appears in a document.

    The core idea behind Multinomial NB is that each document is represented as a bag of words, ignoring grammar and word order, and classified based on the frequency of each word. It assumes that the probability of each word occurring in a document depends only on the document's class (e.g., "sports" or "politics") and that all words are conditionally independent of one another.

    The model estimates the probability of each class given a document by calculating the likelihood of the observed words occurring under each class's learned word distribution. These word distributions are derived from the training data using a modified version of maximum likelihood estimation that includes a smoothing parameter.

    Smoothing plays a critical role in ensuring the robustness of the model. If a word in the test data never appeared in the training set for a particular class, it would otherwise receive a probability of zero, effectively disqualifying the entire class from consideration. To avoid this, techniques such as Laplace smoothing (also known as Add-1 smoothing) are used, which add a small constant to all word counts, ensuring no word has zero probability.

    Why Smoothing is Required

    In the context of Naïve Bayes, one critical issue is the problem of zero probabilities. This happens when a particular feature (such as a word in a document) is not present in the training data for a specific class. Since the Naïve Bayes algorithm multiplies the conditional probabilities of all features, encountering a zero probability causes the entire product to become zero, effectively eliminating that class from being predicted — even if it's the correct one.

    To prevent this, a technique called Laplace Smoothing (also known as Add-1 Smoothing) is applied. This involves adding a small constant value (typically 1) to all feature counts before calculating probabilities. The formula for Laplace-smoothed probability is:

    \( \hat{P}(x_i \mid C_k) = \frac{n_{i,k} + 1}{n_k + V} \)

    Where:

    • \( n_{i,k} \) is the number of times feature \( x_i \) appears in training samples of class \( C_k \)
    • \( n_k \) is the total number of feature occurrences in class \( C_k \)
    • \( V \) is the total number of features (i.e., the vocabulary size)

    This method ensures that no probability is ever zero, which improves model robustness and performance, especially on unseen or rare features during testing.

    Bernoulli Naïve Bayes

    Bernoulli Naïve Bayes is another variant of the Naïve Bayes family, particularly well-suited for binary or boolean features. Unlike Multinomial Naïve Bayes, which works with the frequency of features (like word counts), Bernoulli NB focuses on whether a feature is present or absent — typically represented as 1 (present) or 0 (absent).

    In text classification, this means Bernoulli NB doesn't care how many times a word appears, but rather whether the word appears at all in a document. It evaluates the likelihood of a document belonging to a class based on the presence or absence of key features, making it ideal for binary-valued input features.

    For every word in the vocabulary, the algorithm calculates two probabilities per class:

    • The probability that the word appears in documents of that class
    • The probability that the word does not appear in documents of that class

    During prediction, Bernoulli NB multiplies the probabilities of both present and absent words to compute the posterior probability for each class. The class with the highest posterior is selected as the predicted class.

    Just like with the Multinomial version, smoothing techniques are applied to handle unseen features and prevent zero probabilities, ensuring more stable and generalizable predictions.

    We explored and implemented three variants of the Naïve Bayes algorithm:

    • Multinomial Naïve Bayes: Ideal for features representing counts or discrete bins.
    • Gaussian Naïve Bayes: Assumes continuous features follow a normal distribution.
    • Categorical Naïve Bayes: Works on strictly categorical features encoded as discrete classes.

    Decision Trees (DTs)

    A Decision Tree is one of the most intuitive and widely used supervised machine learning algorithms. It can be applied to both classification (e.g., spam vs. not spam) and regression (e.g., predicting a house price) tasks.

    The core idea behind a decision tree is to break down a complex decision-making process into a series of simple "yes" or "no" questions based on the values of the input features. These questions form the nodes and branches of the tree, while the answers (predictions) sit at the leaf nodes.

    For example, in our asteroid dataset, the model may ask: Is the orbital inclination less than 5 degrees? If yes, it moves left on the tree. If not, it moves right. This process continues until it reaches a leaf node that classifies the asteroid as "Hazardous" or "Not Hazardous."

    Figure 1: A decision tree trained on the Iris flower dataset. It makes decisions like “Is petal length ≤ 2.45?” to classify flowers into species.

    How Do Decision Trees Decide Where to Split?

    At every point in the tree, the model needs to decide which feature to split the data on and what the cutoff value should be. This is done using mathematical metrics that measure how well a split separates the data into homogeneous groups.

    • Gini Impurity: Measures how "impure" a split is. A node where all data points belong to one class has a Gini of 0 (perfect purity).
    • Entropy: Comes from information theory. Like Gini, it measures disorder. Lower entropy means better separation.
    • Information Gain: The amount of impurity that is removed by a split. The higher the gain, the better the feature split.

    Example: Using Entropy and Information Gain

    Imagine we have 10 asteroid records — 5 are hazardous (H), and 5 are not hazardous (N). Before any split, our data is completely mixed, so entropy is at its maximum: 

    Entropy = -0.5 × log₂(0.5) - 0.5 × log₂(0.5) = 1.0

    Now suppose we try to split the data based on the feature earth_moid_au (minimum orbit intersection distance with Earth). We divide the data like this:

    • Group A (earth_moid_au ≤ 0.05): 4 hazardous, 1 not hazardous → entropy ≈ 0.72
    • Group B (earth_moid_au > 0.05): 1 hazardous, 4 not hazardous → entropy ≈ 0.72

    Each group is now slightly more "pure" — not all records are mixed. To calculate the total entropy after the split, we weight each group: 

    
              Weighted Entropy = (5/10 × 0.72) + (5/10 × 0.72) = 0.72
              Information Gain = 1.0 - 0.72 = 0.28

    This means we’ve reduced the uncertainty by 28% with this feature split — which makes it a good candidate for a decision node.

    Why Decision Trees Can Grow Infinitely

    If we allow a decision tree to keep splitting without any restrictions, it will continue until every data point is perfectly separated into its own branch. This results in a very large and complex tree that has "memorized" the training data — a problem called overfitting.

    Overfitting trees perform poorly on new, unseen data because they capture noise rather than patterns. To avoid this, we apply regularization techniques:

    • Max Depth: Limits how many questions the tree can ask (how deep it can go).
    • Min Samples per Split: Requires a minimum number of data points before a node can be split.
    • Pruning: Trims unnecessary branches after the tree has been trained.

    By applying these controls, we can create trees that are not only accurate but also generalize well to unseen asteroid data, helping us predict which ones may pose a risk to Earth.

    Regression Models in Asteroid Hazard Prediction

    a) What is Linear Regression?

    Linear Regression is one of the simplest and most widely used predictive modeling techniques. It attempts to establish a straight-line relationship between one or more input variables (features) and a continuous output variable. For example, it might predict an asteroid's size based on its brightness or distance from the sun. The model fits a best-fit line through the data by minimizing the difference between actual and predicted values using a technique called least squares minimization. However, since its output is continuous, it is not suitable for tasks where we need to classify data into categories like "hazardous" or "not hazardous."

    b) What is Logistic Regression?

    Logistic Regression is a classification algorithm used when the target variable is categorical — most often binary, like 0 (not hazardous) or 1 (hazardous). Instead of predicting a numeric value like Linear Regression, it predicts the probability of an outcome using a mathematical function called the Sigmoid function. This function maps the output between 0 and 1, making it ideal for determining whether an object falls into one of two classes. Based on this probability, we assign a final classification using a decision threshold (usually 0.5). It is especially powerful in real-world problems where probabilistic interpretations of predictions are useful.

    c) How are Linear and Logistic Regression similar and different?

    Both are supervised learning models that use a linear combination of input features to make predictions. However, their goals and outputs differ significantly: Linear Regression predicts a continuous number, while Logistic Regression predicts a probability for a binary class. Logistic Regression also applies the Sigmoid function to its output to interpret it as a probability, whereas Linear Regression directly uses the result of the weighted sum. Additionally, Logistic Regression is optimized using a technique called Maximum Likelihood Estimation (MLE), rather than minimizing squared error.

    d) Does Logistic Regression use the Sigmoid function? Explain.

    Yes, the Sigmoid function is at the core of Logistic Regression. It transforms any real-valued number (which could range from negative to positive infinity) into a probability between 0 and 1. This makes it ideal for binary classification tasks like determining if an asteroid is hazardous or not. The curve of the Sigmoid function smoothly transitions between these two outcomes, allowing us to set a cutoff point (like 0.5) to decide on the classification. Without the Sigmoid function, Logistic Regression would not be able to map outputs to probabilities.

    e) How is Maximum Likelihood Estimation used in Logistic Regression?

    Maximum Likelihood Estimation (MLE) is the method used to find the best-fitting coefficients in a Logistic Regression model. It works by calculating the probability of observing the actual labels in the training data, given a set of model parameters, and then adjusting those parameters to maximize this probability. In simpler terms, it tries to make the model as likely as possible to correctly predict the known outcomes. MLE ensures that the logistic model doesn't just memorize the data but generalizes well by assigning high probabilities to correct labels. This optimization makes logistic regression both robust and mathematically sound.

    Regression is a supervised machine learning technique used to model the relationship between one or more input variables (features) and a continuous or categorical output (target). It helps us make predictions based on historical data.

    Support Vector Machine (SVM) Overview

    What is Support Vector Machine (SVM)?

    Support Vector Machines (SVMs) are powerful supervised learning algorithms that are primarily used for binary classification tasks. The central idea behind an SVM is to find a boundary — called a hyperplane — that best separates the two classes of data. What makes SVMs unique is that they do not just seek any separating line; rather, they find the line (or hyperplane) that maximizes the margin — the distance between the hyperplane and the nearest data points from either class. These nearest data points are called support vectors, and they are critical because they determine the position and orientation of the separating hyperplane.

    SVMs are highly versatile because they can handle both linearly separable and non-linearly separable data. When data is linearly separable, SVMs find the best straight-line division. When data is not easily separable, SVMs can project data into a higher-dimensional space using a technique called the kernel trick, allowing a linear separator to exist in this new transformed space. This approach makes SVMs particularly effective in complex classification problems where other methods might struggle.

    Additionally, SVMs are robust against overfitting, especially when the data has clear margins of separation. Through careful tuning of parameters like the C value (regularization parameter) and choosing appropriate kernel functions (such as linear, polynomial, or radial basis function (RBF)), SVMs can achieve high classification accuracy on both training and unseen data.

    Figure 1: SVM finds the hyperplane that maximizes the margin between two classes.

    Why are SVMs Linear Separators?

    At their core, SVMs are designed to find a linear separator between two classes of data points. A linear separator is a hyperplane that splits the feature space into two halves, with each half corresponding to a different class. Even when dealing with complex, nonlinear data distributions, SVMs fundamentally aim to create a linear boundary — but they do so in a higher-dimensional feature space where the data becomes linearly separable.

    This is achieved through the use of kernel functions. A kernel function computes the dot product of two data points in a transformed space without explicitly mapping the data to that space. As a result, SVMs are able to operate in an extremely high-dimensional space (even infinite-dimensional, as with the RBF kernel) while still maintaining a computationally efficient model.

    No matter the complexity of the transformation, the decision boundary produced by an SVM is always a linear hyperplane in the transformed feature space. In the original input space, this boundary may appear nonlinear — but in the transformed space, it is linear. This elegant approach allows SVMs to handle highly complex data while still relying on the concept of linear separation.

    Dot Product and Kernel Usage in SVMs

    Importance of the Dot Product in Kernels

    The dot product plays a fundamental role in how Support Vector Machines (SVMs) use kernel functions. In machine learning, the dot product measures the similarity between two vectors. For a linear SVM, the decision function relies directly on dot products between input data and the support vectors to classify new points.

    When the data is not linearly separable, the SVM uses a kernel trick to implicitly map the data into a higher-dimensional feature space. Instead of explicitly computing the coordinates in this higher space, the kernel function calculates the dot product between data points as if they were mapped into that space.

    Thus, **kernels allow SVMs to operate efficiently** by using the dot product as a shortcut — avoiding the computational cost of high-dimensional transformations. The dot product is embedded inside every kernel function, whether it is a linear, polynomial, or radial basis function (RBF) kernel. Without the dot product, kernels would not be able to capture relationships between data points or create complex decision boundaries effectively.

    Common Kernels and Their Equations

    Linear Kernel

    \( K(x, y) = x \cdot y \)

    where \( x \) and \( y \) are feature vectors, and \( \cdot \) denotes the dot product.

    Polynomial Kernel

    \( K(x, y) = (r + x \cdot y)^d \)

    where \( r \) is a free parameter (usually 0 or 1), \( d \) is the degree of the polynomial, and \( x \cdot y \) is the dot product between feature vectors.

    RBF (Radial Basis Function) Kernel

    \( K(x, y) = \exp(-\gamma \|x - y\|^2) \)

    where \( \gamma \) controls the spread of the kernel, and \( \|x - y\|^2 \) is the squared Euclidean distance between feature vectors.

    Figure 2: Different SVM kernels: Linear, Polynomial, and RBF.

    Example: Mapping 2D Points with a Polynomial Kernel

    Polynomial Kernel Transformation with r = 1, d = 2

    Let's consider a simple 2D input vector:

    \( \mathbf{x} = (x_1, x_2) \)

    When applying a polynomial kernel with a free parameter \( r = 1 \) and degree \( d = 2 \), the mapping is based on the kernel function:

    \( K(\mathbf{x}, \mathbf{y}) = (1 + \mathbf{x} \cdot \mathbf{y})^2 \)

    For a single point, we effectively transform the original 2D feature vector into a new 3-dimensional feature space:

    \( \phi(\mathbf{x}) = (x_1^2, \sqrt{2} x_1 x_2, x_2^2) \)

    Here:

    • \( x_1^2 \) represents the square of the first feature
    • \( \sqrt{2} \, x_1 x_2 \) captures the interaction between the two features
    • \( x_2^2 \) represents the square of the second feature

    By mapping the original data into a higher-dimensional space, the SVM can now find a linear separator in this new space — even though the original data may not have been linearly separable in two dimensions. This powerful technique enables SVMs to tackle complex classification tasks using relatively simple mathematical tools.

    Ensemble Learning Overview

    Ensemble learning is a powerful machine learning technique where multiple models are combined together to solve a problem and improve performance. Instead of relying on a single model, ensemble methods aggregate the predictions of several models to produce a stronger overall prediction. Ensembles help in reducing variance (overfitting), bias (underfitting), and improve predictive performance on unseen data.

    There are various types of ensemble methods, such as Bagging, Boosting, Stacking, and Voting. Some well-known examples include Random Forest, XGBoost, AdaBoost, and Voting Classifiers.


    Figure: Ensemble learning combines multiple models to improve prediction accuracy.

    Random Forest Overview

    Random Forest is an ensemble learning method that builds a "forest" of multiple Decision Trees during training and outputs the class that is the majority vote of all the trees. It uses a technique called Bagging (Bootstrap Aggregating) where each tree is trained on a different random subset of the training data with replacement. Additionally, Random Forest introduces randomness by selecting a random subset of features for each tree split, making the trees diverse and reducing correlation between them.

    In this project, Random Forest is applied to predict whether an asteroid is potentially hazardous based on its orbital and physical characteristics. By aggregating the decisions of many individual Decision Trees, Random Forest helps achieve high accuracy while reducing overfitting risks compared to a single tree.
